## 📦 Cara Mempublikasikan ke GitHub Pages (Hanya 2 Menit!)

### Langkah 1: Buat Repositori Baru di GitHub
1. Buka [GitHub.com/new](https://github.com/new).
2. Beri nama repositori, misalnya: `portfolio` atau `aziznoviyanto.github.io`.
3. Pilih **Public**. Jangan centang README/license (karena sudah dibuatkan di sini).
4. Klik **Create repository**.

### Langkah 2: Push Kode dari Komputer Anda
Buka Terminal di folder ini (`/Users/soetomo_1/Projects/Pribadi/Portofolio`), lalu jalankan perintah berikut (ganti `<username-github-anda>` dan `<nama-repo>`):

```bash
git init
git add .
git commit -m "feat: inisialisasi portofolio freelance Mochamad Aziz Noviyanto"
git branch -M main
git remote add origin https://github.com/<username-github-anda>/<nama-repo>.git
git push -u origin main
```

*(Atau jalankan `./push-to-github.sh` yang telah disediakan).*

---

### Langkah 3: Aktifkan GitHub Pages
1. Di halaman repositori GitHub Anda, klik tab **Settings**.
2. Pada menu sidebar sebelah kiri, klik **Pages**.
3. Pada bagian **Build and deployment**:
   - **Source**: Pilih **Deploy from a branch**.
   - **Branch**: Pilih `main` dan folder `/ (root)`.
   - Klik **Save**.
4. Tunggu sekitar 1 menit. Link portofolio Anda akan langsung aktif di:
   ```
   https://<username-github-anda>.github.io/<nama-repo>/
   ```
   *(Atau jika nama repositori Anda `username.github.io`, maka link-nya langsung `https://<username>.github.io`)*.
